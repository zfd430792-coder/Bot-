# 💞 Бот знакомств для Telegram

Полноценный бот знакомств на **aiogram 3** и **SQLite**: собственная капча,
пошаговая анкета с фото/видео, поиск по городу, области и расстоянию,
лимит лайков, верификация анкет и админ-панель со статистикой и рассылкой.

Внешние сервисы не нужны — бот работает офлайн, справочник городов
(385 городов, 172 региона) лежит внутри проекта.

---

## Быстрый старт

```bash
git clone <репозиторий>
cd Bot-

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env          # вписать BOT_TOKEN и ADMIN_IDS

python3 main.py
```

**Что нужно указать в `.env`:**

| Переменная  | Где взять                                            |
|-------------|------------------------------------------------------|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot`      |
| `ADMIN_IDS` | свой ID через [@userinfobot](https://t.me/userinfobot) |

Остальные параметры имеют разумные значения по умолчанию — список ниже.

## Как это выглядит для пользователя

1. **Капча.** Картинка с 15 клетками и задание вида «выберите все синие
   квадраты». Нужно отметить все подходящие клетки и ни одной лишней.
2. **Приветствие** с кнопкой «Далее».
3. **Предупреждение о мошенниках** — приветствие удаляется, вместо него
   появляется памятка про скам, фишинг и просьбы о деньгах. Кнопка «Принимаю»
   появляется только через 5 секунд, чтобы её нельзя было пролистать не читая.
4. **Анкета по шагам:** пол → кого искать → возраст → имя → фото или видео
   (до 15 секунд, можно кружком) → о себе → город.
5. **Выбор охвата поиска:** только свой город, вся область или по расстоянию
   (если человек поделился геопозицией).
6. **Лента анкет:** ❤️ / 👎 / 🚨 пожаловаться. При взаимной симпатии бот
   присылает обоим контакт собеседника.

## Собственная капча

Готовые капчи (искажённый текст, «нажми на кнопку», примеры на сложение)
обходятся скриптом за пару минут: текст читает OCR, а ответ обычно лежит
прямо в `callback_data`. Здесь сделано иначе.

| Приём | Что даёт |
|-------|----------|
| Ответ есть только на картинке | ни в сообщении, ни в кнопках подсказки нет |
| Номера клеток нарисованы **вектором** (семисегментные цифры) | не зависит от шрифтов в системе, не похоже ни на один готовый датасет |
| Номера **перемешаны** | кнопка «7» — не седьмая клетка, а та, где нарисована семёрка |
| `callback_data` — случайные токены | все кнопки выглядят одинаково для скрипта |
| Нужно выбрать **все** верные клетки и ни одной лишней | перебор даёт ~1/455 (3 верных из 15), «выбрать всё» не срабатывает |
| Ловушки: та же фигура другого цвета, тот же цвет другой фигурой | ломает наивную классификацию по цвету или форме |
| Сеточная деформация, шум, повороты и дрожание контуров | каждая картинка уникальна, шаблонное сравнение не работает |
| Замер времени | мгновенный ответ (< 2 сек) считается ботовским, долгий — протухает |
| 3 попытки, затем блокировка на 15 минут | подбор становится бессмысленным по времени |

Каждая неудача выдаёт **полностью новое задание** — исключить неверные
варианты нельзя.

## География: город, область, расстояние

Бот понимает три режима поиска, переключаются в ⚙️ Настройках:

* **🏙 Только мой город** — совпадение по названию города;
* **🗺 Вся область** — все анкеты региона (Московская область, Татарстан,
  Краснодарский край и т. д.);
* **📍 По расстоянию** — все, кто ближе N км; доступен, если человек поделился
  геопозицией. Радиус настраивается от 5 до 500 км.

Как это устроено:

* локальный справочник `app/data/cities.json` — 385 городов России, Беларуси,
  Казахстана, Украины и других стран с координатами и регионами;
* распознаются сокращения и опечатки: `мск`, `спб`, `екб`, `нн`, `Алма-Ата`,
  `казан`, `Масква`;
* **если города нет в справочнике** — бот спрашивает область и работает по ней,
  а название посёлка сохраняет как есть (жители одного посёлка всё равно
  находят друг друга);
* геопозиция превращается в город обратным поиском по справочнику;
* расстояние считается функцией `dist_km`, зарегистрированной прямо в SQLite,
  поэтому поиск «рядом» — это один запрос с предварительной отсечкой по рамке
  координат.

**Приватность.** Точные координаты не показываются никому. При приёме
геопозиции они сдвигаются на случайные ~350 метров, а собеседник видит только
округлённое расстояние («~15 км от вас»). Восстановить адрес перебором лайков
невозможно.

Справочник пересобирается из `tools/build_cities.py`:

```bash
python3 tools/build_cities.py
```

Нужны города за пределами справочника — включите онлайн-геокодер
(OpenStreetMap Nominatim), результаты кешируются в базе:

```env
GEOCODER_ENABLED=1
GEOCODER_EMAIL=you@example.com
```

## Защита и модерация

* **Обязательный @username.** Без него бот не пускает: после взаимной симпатии
  собеседнику просто некуда написать.
* **Лимит лайков** — 50 в сутки по умолчанию, меняется в админ-панели на лету.
* **18+** — возраст меньше 18 не принимается ни на регистрации, ни при
  редактировании.
* **Фильтр ссылок** в имени и описании — ни `t.me/`, ни `http://`, ни
  приглашений в чужие чаты.
* **Антифлуд** — ограничение частоты действий на каждого пользователя.
* **Жалобы** приходят только администратору, вместе с карточкой нарушителя и
  кнопками «Забанить / Запросить верификацию / Отклонить». Автор жалобы
  собеседнику не раскрывается.

### Верификация

Два сценария:

* **Пользователь сам просит галочку** — бот работает как обычно, в анкете
  появляется ☑️ после подтверждения.
* **Администратор требует проверку** — бот для этого человека закрывается
  полностью, анкета скрывается из поиска. Пока администратор не подтвердит
  заявку, при любом действии бот показывает требование верификации.

Проверка простая: бот выдаёт код (например, `K7M2`), человек фотографируется
с этим кодом на листе бумаги, фото уходит администратору с кнопками
«Подтвердить / Отклонить / Забанить». Фото проверки в анкету не попадает.

## Админ-панель

Открывается командой `/admin` или кнопкой 🛠 в меню (видна только админам).

| Раздел | Что умеет |
|--------|-----------|
| 📊 **Статистика** | всего пользователей, конверсия в анкету, приток за день/неделю, активность за сутки/неделю/месяц, соотношение полов, средний возраст, лайки, совпадения и доля взаимности, жалобы, статистика капчи, топ городов |
| 📢 **Рассылка** | 9 аудиторий (все, с анкетой, активные за 7/30 дней, спящие, не дозаполнившие, парни, девушки, по городу), предпросмотр, прогресс-бар, учёт заблокировавших бота |
| 🚨 **Жалобы** | очередь открытых жалоб с карточкой анкеты и действиями в один клик |
| ☑️ **Верификация** | очередь заявок, подтверждение, отклонение с причиной, бан прямо из заявки |
| 🔎 **Поиск пользователя** | по ID или @username, полная карточка со статусами |
| 🚫 **Бан / разбан** | бессрочно или на срок (`7d спам`, `12h реклама`), с уведомлением пользователя; истёкшие баны снимаются автоматически |
| ⚙️ **Настройки бота** | лимит лайков, открыть/закрыть приём новых анкет |
| ✉️ **Написать пользователю** | сообщение от имени администрации |

Команды для быстрой работы:

```
/admin                      панель
/stats                      статистика
/find 123456789             карточка пользователя
/ban 123456789 7d спам      бан на 7 дней
/unban 123456789            снять бан
/verify 123456789           потребовать верификацию
/say 123456789 текст        написать пользователю
/broadcast                  рассылка
```

**Журнал событий** (новые пользователи, заполненные анкеты, баны, жалобы,
верификации, блокировки по капче) приходит в чат из `LOG_CHAT_ID`, а если он не
задан — первому администратору из `ADMIN_IDS`.

| Переменная | По умолчанию | Назначение |
|---|---|---|

| `MAX_VIDEO_SECONDS` | `15` | максимальная длина видео в анкете |
| `RULES_DELAY_SECONDS` | `5` | пауза перед кнопкой «Принимаю» |
| `CAPTCHA_MAX_ATTEMPTS` | `3` | попыток до блокировки |
| `CAPTCHA_MAX_REFRESH` | `3` | сколько раз можно сменить картинку |
| `CAPTCHA_BLOCK_MINUTES` | `15` | длительность блокировки |
| `CAPTCHA_TIMEOUT_SECONDS` | `150` | через сколько задание протухает |
| `CAPTCHA_MIN_SOLVE_MS` | `2000` | быстрее — считаем ботом |
| `THROTTLE_SECONDS` | `0.4` | минимальный интервал между действиями |
| `GEOCODER_ENABLED` | `0` | онлайн-геокодер для неизвестных городов |
| `GEOCODER_EMAIL` | — | контакт для User-Agent Nominatim |

## Тесты

Сквозной прогон проверяет весь путь пользователя без обращения к Telegram —
реальный токен не нужен:

```bash
python3 tests/smoke_test.py
```

Проверяются: капча (верный ответ, неверный, слишком быстрый), удаление
приветствия и задержка перед «Принимаю», валидация возраста/имени/описания,
ограничение длины видео, запасной путь через область, геопозиция и сдвиг
координат, лента и совпадения, лимит лайков, жалобы, админ-панель, статистика,
принудительная верификация, бан и разбан, рассылка, настройки поиска, скрытие
и удаление анкеты.

## Запуск на сервере

```ini
# /etc/systemd/system/dating-bot.service
[Unit]
Description=Telegram dating bot
After=network-online.target

[Service]
Type=simple
User=botuser
WorkingDirectory=/opt/dating-bot
ExecStart=/opt/dating-bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now dating-bot
sudo journalctl -u dating-bot -f
```

Резервная копия — это один файл (`data/bot.db`). База работает в режиме WAL,
копировать можно на ходу:

```bash
sqlite3 data/bot.db ".backup '/backup/bot-$(date +%F).db'"
```

## Заметки по данным

* Хранится минимум: анкета, округлённые координаты, реакции, жалобы и журнал
  модерации.
* Точные координаты не хранятся и никому не показываются.
* Фото верификации доступно только администратору и в анкету не попадает.
* Удаление анкеты стирает данные профиля, лайки и совпадения; запись о
  пользователе остаётся только для того, чтобы помнить бан и капчу.
